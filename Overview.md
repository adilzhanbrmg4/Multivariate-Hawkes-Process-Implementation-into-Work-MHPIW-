We will be integrating Multivariate Hawkes Process and Rough Path Theory in this paper. To start, let's define what we are working with. 
**Rough Path Theory**
Let ∆T = {(s, t) : 0 ≤ s ≤ t ≤ T }. A control function is a continuous map ω: ∆T → [0, ∞) which is super-additive,
i.e. ω(s, t) + ω(t, u) ≤ ω(s, u) for all 0 ≤ s ≤ t ≤ u ≤ T. Here the control function means that changes in one of the variables will lead to deterministic result,
as per Control Theory. We also deal with super additive function here, i.e value of combined values is equal or greater than the sum of those two variables.
